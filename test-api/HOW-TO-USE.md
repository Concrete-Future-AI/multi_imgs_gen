# 🎨 Pipeline使用说明

## ✨ 新增功能

现在支持**两种类型**的图片生成：

1. **产品特写图** - 纯净背景，突出产品细节
2. **场景图** - 产品在真实场景中，生活方式展示

---

## 🚀 使用方法

### 方式1：命令行参数（快速）

#### 生成产品特写图
```bash
# 使用默认图片 stone_img.jpg
npm run pipeline:closeup

# 或使用自定义图片
node pipeline-full.js 你的图片.jpg closeup
```

#### 生成场景图
```bash
# 必须提供场景描述
node pipeline-full.js stone_img.jpg scene "木质咖啡桌上，旁边有一杯拿铁咖啡和一本打开的书，温暖的午后阳光"
```

---

### 方式2：交互式菜单（友好）

```bash
# 运行交互式版本
npm run pipeline:interactive

# 或
npm start
```

**交互流程：**
1. 显示欢迎界面
2. 选择类型（输入 1 或 2）
   - 1 = 产品特写图
   - 2 = 场景图
3. 如果选择场景图，输入场景描述
4. 按 Enter 开始生成

## 🎯 场景描述技巧

### 好的场景描述包含：

1. **场景位置**
   - 例如：木质桌面、户外草地、卧室床头柜

2. **环境元素**（2-3个即可）
   - 例如：咖啡杯、书本、植物、MacBook

3. **光线氛围**
   - 例如：温暖的午后阳光、柔和的晨光、自然光线

4. **整体风格**（可选）
   - 例如：北欧简约、现代极简、温馨居家

### ✅ 推荐示例

```
"木质咖啡桌上，旁边有一杯拿铁咖啡和一本打开的书，温暖的午后阳光"

"现代办公桌面，MacBook旁边，极简北欧风格，自然光线"

"温馨卧室床头柜上，柔和的晨光透过纱帘，旁边有小台灯"

"户外阳台，柔和的傍晚光线，背景虚化的城市景观"
```

### ❌ 避免

```
"在桌子上"  ❌ 太简单，缺少细节

"豪华的金色宫殿里，四周有各种珠宝..." ❌ 过于复杂，喧宾夺主

"随便什么地方都行" ❌ 不明确
```

## 💡 使用建议

1. **先生成特写图**
   - 用于电商主图和详情页
   - 突出产品本身

2. **再生成场景图**
   - 用于软文和氛围营销
   - 1-2个场景即可

3. **场景要简洁**
   - 元素不要太多（2-3个）
   - 确保产品为主体

4. **批量生成**
   - 可以运行多次，每次不同场景
   - 文件会自动命名，不会覆盖

---

## ⚠️ 注意事项

1. **API限流**
   - 建议两次生成间隔5秒以上
   - 避免频繁调用

2. **场景描述必填**
   - 选择scene类型时必须提供场景描述
   - 否则会报错

3. **命令行引号**
   - 场景描述包含空格时必须用引号
   - 正确：`"木质桌面 咖啡"`
   - 错误：`木质桌面 咖啡`

4. **主体一致性**
   - Pipeline会严格保持产品特征
   - 无论特写图还是场景图
