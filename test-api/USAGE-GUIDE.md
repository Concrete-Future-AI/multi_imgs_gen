# 📖 Pipeline使用指南

## 🎯 功能说明

Pipeline支持生成两种类型的电商图片：

### 1️⃣  产品特写图（默认）
- **特点**：纯净背景（纯白或浅灰色）
- **适合**：展示产品细节、电商主图
- **风格**：专业摄影棚风格

### 2️⃣  场景图
- **特点**：产品放置在真实场景中
- **适合**：生活方式展示、氛围营销
- **风格**：自然场景、生活化
- **需要**：提供场景描述

---

## 🚀 使用方法

### 方法1：使用npm脚本（快速）

#### 生成产品特写图
```bash
npm run pipeline:closeup
```

#### 生成场景图（需要修改命令添加场景描述）
```bash
# 编辑package.json中的scene命令，添加场景描述
npm run pipeline:scene
```

### 方法2：使用node命令（灵活）

#### 基本语法
```bash
node pipeline-full.js [图片路径] [类型] [场景描述]
```

**参数说明**：
- `图片路径`：可选，默认使用 `stone_img.jpg`
- `类型`：`closeup`（产品特写图）或 `scene`（场景图）
- `场景描述`：当类型为 `scene` 时必需

## 💡 场景描述技巧

### 好的场景描述应该包含：

1. **场景位置**
   - 例如：木质桌面、户外草地、卧室床头柜

2. **环境氛围**
   - 例如：温馨、现代、北欧风、复古

3. **光线条件**
   - 例如：自然光、柔和晨光、阳光明媚

4. **周围元素**（可选）
   - 例如：咖啡杯、书本、植物、MacBook
   - 注意：不要太多，2-3个即可

5. **背景处理**
   - 例如：背景虚化、模糊的绿色植物

### ✅ 好的示例

```
"木质餐桌上，温暖的午后阳光，旁边有一杯茶和小花瓶"
"现代极简风格的白色桌面，自然光线，背景是浅灰色墙面"
"户外阳台，柔和的傍晚光线，背景虚化的城市景观"
```

### ❌ 不好的示例

```
"在桌子上"  ❌ 太简单，缺少细节
"豪华的金色宫殿里，四周有各种珠宝和装饰品..." ❌ 过于复杂，喧宾夺主
"随便放在什么地方都行" ❌ 不明确
```

### 产品特写图 vs 场景图

| 特征 | 产品特写图 | 场景图 |
|-----|-----------|--------|
| 背景 | 纯白/浅灰 | 真实场景 |
| 光线 | 专业打光 | 自然光线 |
| 元素 | 仅产品 | 产品+环境 |
| 风格 | 专业电商 | 生活方式 |
| 适用 | 主图、详情页 | 软文、氛围图 |
| 耗时 | ~2.5分钟 | ~2.5分钟 |

## 🔧 高级用法

### 使用不同的产品图片

```bash
# 指定自己的图片
node pipeline-full.js /path/to/my-product.jpg closeup

# 场景图
node pipeline-full.js /path/to/my-product.jpg scene "你的场景描述"
```

### 批量生成

```bash
# 生成两种类型
node pipeline-full.js stone_img.jpg closeup
node pipeline-full.js stone_img.jpg scene "木质桌面，咖啡和书本"
```

### 生成数量
默认生成5张不同视角的图片，修改 `pipeline-full.js` 中的：
```javascript
const stats = {
  totalImages: 5, // 改为你想要的数量
  // ...
};
```

### 输出位置
所有图片保存在：`test-api/output/generated/`

- 产品特写图：`ecommerce_正面特写_时间戳_序号.png`
- 场景图：`ecommerce_正面特写_时间戳_序号.png`（使用相同命名）

## 📈 最佳实践

### 1. 先生成特写图
建议先生成产品特写图，用于电商主图和详情页

### 2. 再生成场景图
根据产品定位和营销需求，生成1-2个场景图

### 3. 场景要简洁
场景元素不要太多，2-3个辅助元素即可

### 4. 保持产品为主体
无论什么场景，产品都应该是画面的主体

---

## ⚠️ 注意事项

1. **场景描述必填**
   - 选择`scene`类型时，必须提供场景描述
   - 否则会报错并退出

2. **场景不要太复杂**
   - 过于复杂的场景可能导致产品不突出
   - 建议简洁、干净的场景

3. **保持产品一致性**
   - AI会严格保持产品特征100%一致
   - 无论是特写图还是场景图

4. **命令行引号**
   - 场景描述包含空格时，必须用引号括起来
   - 正确：`"木质桌面 咖啡"`
   - 错误：`木质桌面 咖啡`

---

## 🐛 故障排除

### 问题1：提示"必须提供场景描述"

**原因**：选择了scene类型但没有提供场景描述

**解决**：
```bash
# 正确的方式
node pipeline-full.js stone_img.jpg scene "木质桌面上"
```

### 问题2：场景描述被截断

**原因**：没有使用引号

**解决**：
```bash
# 使用引号包裹场景描述
node pipeline-full.js stone_img.jpg scene "完整的场景描述，包含空格"
```

### 问题3：生成的场景图产品不一致

**原因**：场景描述过于复杂或干扰了产品识别

**解决**：
- 简化场景描述
- 强调产品为主体
- 确保场景元素不会遮挡产品
