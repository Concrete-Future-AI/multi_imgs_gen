## ⚙️ 技术要点

### 1. 避免跨域

**问题**: 直接使用远程URL可能遇到跨域限制

**解决**: 
- 所有图片下载到本地
- 保存在 `output/generated/` 目录
- 使用本地路径访问

### 2. API URL要求

**豆包API限制**: `image` 参数必须是公网URL

**解决方案**:
- 测试环境：使用豆包官方示例图
- 生产环境：上传到S3/OSS获取URL

### 3. 主体一致性

**挑战**: AI生成容易改变产品特征

**优化**:
- Prompt明确强调"100%一致"
- 使用"禁止改变"等否定词
- 参考电商平台的专业标准

---

## 🎨 Prompt设计策略

### 结构化Prompt

```
1. 严格要求（最重要）
   └─ 主体一致性声明

2. 产品信息
   └─ 详细的产品描述

3. 电商摄影标准
   ├─ 背景要求
   ├─ 光线要求
   └─ 构图要求

4. 拍摄视角
   └─ 5个具体角度

5. 禁止事项
   └─ 明确不允许的操作
```

### 关键词选择

✅ **有效的关键词**:
- "100%保持一致"
- "完全相同"
- "禁止改变"
- "严格要求"

❌ **避免的表达**:
- "尽量保持" (模糊)
- "可以变化" (会导致不一致)
- "类似于" (不够精确)
